Core Capabilities

Audit Mode First

Read-only by default. Compares ERP prices against platform state and last gateway ACK. Reports mismatches without silent overwrites.

Delta Discipline

No full-catalog pushes. Computes changed SKUs since the last watermark and pushes only deltas to conserve bandwidth and battery.

Idempotency & Rate Limits

Every price command carries an ERP transaction ID. Updates are capped at 75-80% of radio throughput to prevent gateway overload.

Comprehensive Audit Trail

Links every label update back: ERP transaction → transform timestamp → platform ACK → label confirm.
